# k3GPT

#### 介绍
一个大模型驱动的知识共享平台，包括知识搜索、知识对话、知识创作等能力，因此称为knowledge x 3的GPT平台,简称k3GPT.  
可以将私域知识文档轻松的聚合沉淀，让人更好的使用知识，让知识流动起来！

#### 软件架构
深度基于全文搜索的架构搭建的GPT平台，比向量模型的准确度更好，详细见《全文检索笔记.txt》


#### 安装教程
详见《安装.txt》文档

#### 功能特点

1.  支持本地部署大模型，提供了llama.cpp和Qwen2.5-7B的安装包，更容易部署
2.  支持windows共享、ftp、sftp等文件服务器，支持海量文件的聚合搜索
3.  支持在线AI编辑创作知识百科、词条
4.  支持使用云上的大模型API,减少大模型部署的成本
